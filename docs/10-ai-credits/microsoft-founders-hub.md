# Microsoft for Startups Founders Hub

## Credit amount

- **Baseline:** $5,000 in Azure credits (often easy to obtain)
- **Higher tiers:** Up to $25,000 in Azure credits + access to OpenAI via Azure
- **All tiers also include:** GitHub Enterprise, LinkedIn Sales Navigator, Microsoft 365 Business — sometimes worth more than the API credits if you'd otherwise pay for them.

## Who qualifies

- Building anything (broad criteria — Microsoft accepts most legitimate startups)
- Pre-Series C
- Have at minimum an idea + plan (no revenue requirement)
- One application per startup

This is the **easiest of the four** to get approved for. Often days, not weeks.

## What's notable

Microsoft's Azure offers **OpenAI models** via Azure OpenAI Service. So a Microsoft credit also indirectly grants you OpenAI access (different terms than direct OpenAI billing).

You can also use these credits for:
- Hosting (Azure App Services, Functions)
- Databases (Cosmos DB, PostgreSQL)
- Storage (Blob)
- Other Microsoft services

## What to prepare

Same materials as Anthropic (see `anthropic-startup.md`). Microsoft's form is simpler — less detailed than Anthropic.

## How to apply

1. Visit https://foundershub.startups.microsoft.com
2. Click "Get started"
3. Sign in with Microsoft account (or create one)
4. Fill the form
5. Submit

Typical response: **3–7 days**.

## Tips

- **Microsoft loves multi-platform startups.** Mention if you'd consider Azure for hosting (you don't have to commit).
- **Be specific about timeline.** "Plan to ship by Q3 2026" beats "soon."
- **Higher tier requires investor connections.** Apply baseline first; upgrade later if needed.

## Bundled benefits worth claiming

Even if you don't use the API credits, these are valuable:
- GitHub Enterprise (private repos, advanced features)
- LinkedIn Sales Navigator (Premium-level account-finding)
- Microsoft 365 (Word/Excel/Teams business edition)
- Microsoft Learn paid courses

For a solo founder, this bundle alone is worth $1,500+/year.

## After approval

- Credits appear in Azure Portal (Cost Management)
- GitHub / LinkedIn / 365 access activated separately (check email for codes)
- Credit consumption tracked in Azure dashboard

## If rejected

Rare. If it happens:
- Verify your application was complete
- Ensure you didn't apply previously and forget
- Reapply with sharper project description
