# OpenAI for Startups

## Credit amount

- **Baseline (no VC):** ~$1,000 in OpenAI API credits
- **With VC partnership:** Up to $50,000

The full $50K typically requires affiliation with a partner accelerator or fund (Y Combinator, Sequoia, etc.).

## Who qualifies

- Building with OpenAI models (GPT, DALL-E, embeddings)
- Early-stage (typically pre-Series B)
- Not currently spending >$10K/month with OpenAI

If you're using OpenAI alongside Claude through Corpify (e.g., GPT for image generation tasks while Claude handles reasoning), you qualify.

## What to prepare

Same materials as Anthropic application (see `anthropic-startup.md`), plus:
- **If applicable: list of VC backers** (only if accepting the larger amount)
- **Specific OpenAI use case** — which models, why

## How to apply

1. Visit https://openai.com/startup-program (URL as of June 2026; check for updates)
2. Choose your tier (baseline vs. VC partner track)
3. Fill the form
4. Submit

## Tips

- **Be honest about VC status.** Claiming VC backing without actually having it is grounds for revocation.
- **Highlight non-Claude use cases.** If you're using OpenAI only because you can't use Claude there, mention that — OpenAI wants developers, not just cost-shoppers.
- **Show production usage.** Active monthly spend (even small) signals commitment.

## After approval

- Credits appear in your OpenAI dashboard
- Used automatically before billing
- Expires per terms (usually 12 months)

## If rejected

- Wait cooldown
- Build more, ship more, then reapply

## Honest assessment

OpenAI's program is less generous than Anthropic's for solo founders. **If you have to choose where to spend application effort, prioritize Anthropic Startup Program first.**

If your business needs OpenAI specifically (image generation via DALL-E, fine-tuning, etc.), the $1K baseline is still worth the application — that's a month or two of free usage for most early projects.
